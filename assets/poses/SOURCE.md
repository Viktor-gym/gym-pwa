# Illustrated Exercise Positions

Source: Workout Guide by Bryl Lim, npm `@bryllim/workout-guide@1.0.0`.
https://github.com/bryllim/workout-guide
https://www.npmjs.com/package/@bryllim/workout-guide

The source contains 302 exercises with three drawn positions each, not smooth
3D motion. This release uses 261 guides: 83 linked to existing catalog entries
and 178 additional variants. Existing 68 smooth 3D entries are not altered;
already-covered or duplicate mappings are omitted. A source count is not a
count of additional smooth animations.

Artwork: **CC BY-SA 4.0**. See LICENSE-ASSETS, ATTRIBUTION.md and ATTRIBUTION.json
for the original credits and per-frame attribution, including Everkinetic
source URLs where supplied. https://creativecommons.org/licenses/by-sa/4.0/

Changes: transparent PNG drawings composited on #1c2534, resized to 400 x 400,
and packed into 1200 x 400 WebP strips. Separate 400 x 400 first-position posters
are used in lists. These derived images remain CC BY-SA 4.0. No interpolated
frames, real-person footage or paid media are included. Playback cycles through
the three supplied drawings, with manual position selection and pause/speed.

Source-only entries do not supply written technique. They say this explicitly;
existing linked entries keep their original instructions. Broad source muscle
labels are shown as provided, without inventing detailed anatomical highlights.
