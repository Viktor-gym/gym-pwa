# Native bench guides

Original two-dimensional exercise renders for GymTracker Pro. Model base: ManuelBastioniLAB / MB-Lab, Manuel Bastioni and contributors. The bundled upstream license explicitly permits ordinary rendered 2D images and videos to have their own license; raw 3D models and databases remain AGPL-3.0. No raw model or private workout export is distributed here. See MBLAB-LICENSE.txt for the exact upstream terms.

Animation, generic equipment and muscle-region illustration were prepared locally in Blender. FitnessOnline was a visual/usability reference; no FitnessOnline artwork was copied. Primary and secondary role metadata comes from the unchanged exact Free Exercise DB catalog bindings. Saturated vs pale highlighting is illustrative, not a measurement of activation.

Existing 68 third-party animations remain unchanged. In particular the existing incline curl guide is retained; unfinished or colliding native variants are not substituted. Base bench uses the previously reviewed native v9 rendered loop, re-encoded for mobile playback. Other packaged native loops are 48 rendered frames at 16 fps.

Technique references: ACE exercise library https://www.acefitness.org/resources/everyone/exercise-library/ ; NASM exercise library https://www.nasm.org/resource-center/exercise-library/ ; Catalyst Athletics https://www.catalystathletics.com/exercise/850/Incline-Dumbbell-Curl/ . These references are not reused media.
